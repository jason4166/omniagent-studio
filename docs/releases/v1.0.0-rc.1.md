# OmniAgent Studio v1.0.0-rc.1

A local release candidate for a configurable, evidence-grounded and approval-controlled Agent workspace. Default Fake mode demonstrates all three Profiles without a model key or real business-system write.

## Included

Durable PostgreSQL/LangGraph sessions and HITL, strict Profile/KB/Tool isolation, safe HTTP/MCP integration, Vue administration and chat, replay-only SSE, deterministic grounding, bounded recovery/retry policies, local OTel, versioned eval/security/performance evidence, Docker Compose and CI definitions.

## Reproduction

```sh
python scripts/ops.py bootstrap
python scripts/ops.py health
python scripts/acceptance.py --output .pytest-tmp-release
```

Open `http://127.0.0.1:8080`. [Demo script](../demo.md), [all gate commands](../development.md), [clean acceptance evidence](../artifacts/release/README.md) and [current metrics](../../README.md#当前可复核指标) provide the reproducible trail. Full source and report identities are recorded separately so an evidence-only commit does not pretend to have tested itself.

## Scope and known failures

The supported candidate is the local Fake/mock product. Developer identities are public local fixtures; real external writes, SSO and multi-organization tenancy are excluded. The frozen Fake candidate has 65/66 successful E2E cases; all three independent safety rates are zero. The optional real model has 2/3 successful cases and exits nonzero on its strict-grounding rejection. This is a measured limitation, not a passing real-model gate.

No remote push, pull request, merge or GitHub Release has been performed. A local release tag and evidence manifest identify the candidate once clean acceptance is complete.
