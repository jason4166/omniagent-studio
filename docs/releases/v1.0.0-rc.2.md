# OmniAgent Studio v1.0.0-rc.2

Local release candidate, 2026-09-11. Runtime verified at `8156cb89cdbbe5b8b19cc63ab20877b9512c1f85`.
No remote publication is performed.

## What changed from rc.1

- Add a real demonstration mode: DeepSeek structured planning and grounded excerpts,
  Zhipu embedding-3 for ingestion and queries, and honest model/embedding labels in Vue.
- Isolate index model, endpoint, dimension and cache versions. Refuse to overwrite a Fake
  installation with real seed. Seed remains idempotent and Profiles share one Runtime.
- Mount credential references through Compose secrets; no literals in YAML, images,
  checkpoints or browser storage. Preserve non-root execution and root-owned application files.
- Add 24 frozen Chinese live cases, exact tool/argument/route scoring, actual usage metrics,
  a separately retained baseline/candidate/retest, and a new-document ingestion proof.
- Correct MCP transport selection and multi-turn routing. Re-run real browser, approval,
  restart, SSE and two paced demonstrations against an isolated clean deployment.

## Running and boundaries

`python scripts/ops.py bootstrap --mode real` uses operator-provided `DEEPSEEK_API_KEY`
and `ZHIPUAI_API_KEY`. `--mode fake` needs no paid key and uses a separate volume.
Do not reuse a Fake index for real embeddings. No existing user data is reset or
migrated to another model automatically.

Business writes remain a local sandbox; DevUserContext is not SSO. Grounding deliberately
uses exact excerpts; vendor aliases, network latency and a small dataset limit quality
claims. SSE streams validated output, not hidden reasoning or unchecked model tokens.
