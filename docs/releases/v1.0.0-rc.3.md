# v1.0.0-rc.3 — Independent accounts and deployment hardening

This local release candidate replaces the shared demonstration identities that
made rc.2 unsuitable for a public multi-user site. It preserves the real DeepSeek /
Zhipu résumé demonstration and all three configuration-driven Agent workflows.

## Changes

- Independent UUID accounts, Argon2id password hashes, admin-managed role/Profile
  grants, password rotation and server-side session revocation. No frontend role
  switch or embedded credential; historical bearer access is test-only.
- HttpOnly/Secure/SameSite cookies, session-bound CSRF, canonical Host/Origin,
  login/request/upload/paid-call quotas in PostgreSQL and bounded SSE leases.
- Random per-installation credentials, distinct owner/API/mock database roles,
  file secret mounts and read-only non-root API/seed containers.
- Production Caddy HTTPS overlay, private internal services, readiness, memory/
  process limits and environment/origin pinning; production refuses offline gates
  and destructive reset.
- Isolated bounded PDF parser; authenticated encrypted backup/new-database restore,
  revoked restored logins and a tamper rejection drill.
- Expanded public-access security cases, cookie-based browser tests, dependency
  audit gates, public deployment instructions, ADR and updated screenshots.

## Validation

Linux and Windows: 618 backend tests each, zero failures/skips. Linux line coverage
5,808/6,742 (86.15%, threshold 80%). Frontend lint/typecheck/build and 20 unit tests
pass; real and Fake browsers each pass five tests without retries. Ruff/check,
format, mypy and diff checks pass. Security: 111 passing tests, 29 versioned attacks,
14 versioned fault scenarios. Known dependency vulnerabilities and source/history/
image/config secret findings are zero in this snapshot.

Real evaluation: 24/24, route/recall/citation/support/tool metrics 100%, argument F1
1.0; unauthorized write, KB isolation and attack rates zero. P50/P95 1,724.32 /
2,534.76 ms; 35 model, 11 retrieval and 8 tool calls, 36,600 chat tokens plus 154
embedding tokens; cost unknown. Fake remains 65/66. Two complete real demonstrations
last 182.16 and 182.19 seconds and pass restart, edited/replayed approval, HTTP/MCP
and SSE checks. [Evidence and scope](../artifacts/release-public/README.md).

## Upgrade and remaining deployment work

Use a new `omniagent-secure-real` or production project. Credentials live under its
private `.local/deployments/<project>` directory. Old demo sessions/approvals remain
in their original volume and are not automatically reassigned to new accounts.
Do not apply the old public role tokens to this version or copy a private directory
into a release archive. The earlier 8080 demo services are stopped; their data is
preserved. Initial account credentials are shown by path, not in documentation.

Local trusted-CA HTTPS and clean volumes are verified. An actual public server,
domain, DNS/firewall, publicly issued certificate, external monitoring and off-host
backup transport require target-environment setup and acceptance. No remote push,
PR, main merge, cloud purchase or remote Release has been performed. No enterprise
SSO, MFA, public registration, real CRM/payment/email writes or production SLA is
claimed. See [public deployment](../public-deployment.md).

Local implementation commits: `142e6e7` (public access/deployment hardening),
`f82b605` (bootstrap-independent test isolation). The tag also includes the final
evidence/documentation commit; runtime files match the validated source above.

The local release package includes a Git bundle and SHA-256 checksums. Clone the
bundle and check out this tag before using `ops.py`, which requires Git metadata
for image revisions. A plain source ZIP alone is not a runnable Git checkout.
