对话通过网站同源 API 执行，与聊天页面使用相同的认证、运行时和审批接口；另用独立浏览器上下文只读检查实际 UI。首次探索的三个独立访客并行进行，但这不是压力或容量测试。只访问本轮创建的测试会话，没有使用其他访客的聊天记录。

折扣追问的初始故障是路由解释错误，原执行记录仍在；不能将其描述成已证实的历史丢失。拒绝追问则确实缺少结构化的未执行记录，本轮补齐。操作追问只引用服务端保留的原始记录，不接受客户端自报的执行参数或状态。

## 仍有的限制

政策回答仍保留完整证据单元，减少重复段落后，部分窄问题仍会返回偏长的原文，连续追问也可能重复同一段。这是当前引用校验方式的可见限制，尚未实现可以独立验证含义的自由改写答案。首轮“八五折呢”只返回政策，没有明确换算成 15% 的优惠；本轮未宣称修复这一类政策计算回答。

本轮重点验证上下文、错误反馈和实际工具效果，不能证明任意问法、任意并发或所有攻击都不会失败。销售工具仍只保存本站业务记录，没有让真实报价折扣生效或发送邮件的能力。旧评测的完整事实保留在版本化记录中，不以展示指标替代已知限制。
