# 工具参数提示与展示额度

应用源码：`43304bfeb9c0ea3ab013e342a8def99e544ca54e`。

申请工具缺少必填信息或参数超出范围时，Runtime 根据服务端工具 Schema 返回具体的补充说明，正常结束当前回复，让用户继续修改。折扣申请初次补充参数时会列出整数、1–20% 的范围；30% 不会被悄悄改成 20%，也不会创建审批或执行记录。

提示只使用当前用户已获授权的工具定义。Profile、角色、工具启用状态和数据库中的当前定义先经过校验；合法参数仍走原有审批、执行时复核和幂等流程。这不是按用户问法逐条添加固定答案。

旧的参数校验或模型响应格式错误显示“修改问题”，将原问题带入新会话草稿，不自动发送或重放操作。旧记录保留。恢复旧运行仍受原预算、截止时间和配置版本约束，不能承诺所有旧失败会话均可恢复。

## 额度口径

三套预置助手使用相同的每轮预算：

| 项目 | 上限 |
| --- | ---: |
| 累计 token 预算占用 | 1,000,000 |
| 模型调用 | 100 |
| 工作流步骤 | 200 |
| 工具调用 | 4 |
| 总执行时间 | 120 秒 |

一轮指一次提交后的工作流运行，不是整个聊天会话。模型调用次数包含路由、生成及重试，不等于提问次数。100 万是累计预算上限，不是模型上下文窗口或单次输出长度；现有上下文、输出长度和外部调用超时限制保持原配置。每日额度或其他执行边界仍可能先到达。

每日额度按 UTC 日期计算，保留原有已用计数：

| 范围 | token 上限 | 模型尝试上限 |
| --- | ---: | ---: |
| 单个用户 | 1,000,000 | 1,000 |
| 全部公开访客合计 | 1,000,000 | 2,000 |
| 全站合计 | 2,000,000 | 10,000 |

公开访客共享额度不能理解为每位访客各有 100 万。已使用量和未结算预留仍占用额度；扩大上限不会重置计数。输入框旁保留本轮与每日的已用量和上限。
